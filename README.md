# Quantum Circuit Exploration with Qiskit

An implementation and analysis of foundational quantum algorithms using IBM's Qiskit framework.

## 🚀 Key Experiments
* **Bell State Generation:** Creating and measuring quantum entanglement.
* **Quantum Teleportation Protocol:** Simulating quantum state transfer using entangled pairs.

## 🛠️ Tech Stack
* Python
* Qiskit & Qiskit Aer (Simulation Backend)
* Matplotlib & Pylatexenc (Circuit Visualization)

## 📦 How to Run Locally
1. **Clone the repo:**
   ```bash
   git clone https://github.com
   cd quantum-qiskit-exploration
   ```
2. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
3. **Launch the environment:**
   ```bash
   jupyter notebook
   ```
